# Smarty Code-Dokumentation

Smarty Code ist der visuelle Arbeitsbereich rund um OpenCode (den KI-Coding-Agenten, der in deinem Terminal läuft). Er gibt dir einen Bildschirm, auf dem du diese Arbeit beobachten und steuern kannst, statt nur auf der Befehlszeile zu arbeiten.

Nutze diese Doku, um:

- die richtige App für deine Arbeitsweise zu installieren
- Smarty Code für den sicheren Remote-Einsatz zu öffnen
- das Aussehen anzupassen und häufige Probleme zu beheben
